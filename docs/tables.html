Pivot above to join with main data such that each ID has only one row.

pmt_tbl = pivotTblData(tbl_dat, "tbl1")

assert len(tm) == len(df)
assert len(tm) == len(pmt_tbl)
assert tm["id"].nunique() == len(tm)

df = _addGroupCol(tm.copy())
