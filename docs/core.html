FormatOptions

 FormatOptions (_format:bool=True, prefix:str='', suffix:str='',
                comma_str:str=',', decimal_str:str='.',
                pad_zeroes_at_end:bool=True,
                return_int_if_possible:bool=False,
                accounting_notation:bool=False, ignore_na:bool=True)

Dataclass storing options/config for numerical formatting. Supports most locale conventions / currency formatting:

    _format: bool = True  # True returns str, False returns float
    prefix: str = ""
    suffix: str = ""
    comma_str: str = ","
    decimal_str: str = "."
    pad_zeroes_at_end: bool = True
    return_int_if_possible: bool = False
    accounting_notation: bool = False  # negative numbers in parentheses
    ignore_na: bool = True  # if input is null, return null

fix_round

 fix_round (num:float|int|None, position:int=0)

Python’s built-in round function can return unexpected results. See https://docs.python.org/3/library/functions.html#round. This function returns the same result as the Excel ROUND function.

Type Default Details
num float | int | None float | int | None
position int 0 int
Returns float | None float | None

add_mailing_details_col

 add_mailing_details_col (df:pandas.core.frame.DataFrame,
                          address_dict:dict,
                          col_name:str='str_mailing_details')

Adds column to dataframe w/ full mailing details in upper case:

<full name>
<street lines (up to 3)>
<city, province  postal code> - handles various combinations of missing data in case of foreign addresses
<country>

If there’s a c/o line, moves it to 2nd line.

address_dict dict see docs for example
